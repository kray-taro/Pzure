## Parallelisation map (work that can run simultaneously)

Mapped to the 5 squads in the Master Plan (Platform & Security, Commerce & Inventory, Clinical & Pharmacy, Claims/Reporting/Comms, QA/Data/Release). A sprint number is the *earliest* it can start once its dependencies are met; squads run their lanes concurrently.

### Hard dependency chain (cannot be parallelised)

```text
#12 Sprint 0 (mobilisation + close blockers #48-#53)
        ↓
#13 Sprint 3 DevSecOps skeleton (auth, RBAC, audit, CI/CD)
        ↓
#14 Sprint 4 Core master data & branch foundation
        ↓
   (all module lanes unlock here)
```

Nothing in the module lanes should start before **#14** lands, because every record is branch-scoped and every action is RBAC + audit gated.
